# Literature notes workflow

## Purpose

This folder stores structured notes on key papers relevant to the project.

The goal is to avoid re-reading papers from scratch every time and instead build a cumulative project-specific literature memory.

## Recommended note structure for each paper

For each important paper, create one note containing:
- full citation
- why the paper matters for this project
- key methods
- key findings
- limitations or assumptions
- what we may reuse
- what gap remains for our project

## Suggested usage

- `refs/core/` for anchor papers central to the project
- `refs/methods/` for modelling or analytical method papers
- `refs/background/` for broader ecological or biogeographical context
- `notes/literature/` for human-readable summaries and synthesis notes

## Working principle

Read each important paper carefully once, summarize it, then revisit only the relevant sections later.

Do not repeatedly read whole papers from scratch unless necessary.

## Future synthesis files

This folder can later include:
- one note per paper
- one cross-paper synthesis document on novelty, methods, and framing
