# Meeting notes, 2026-04-08

## Main outcome

We clarified that the project should not be framed as a direct Dijkstra-versus-Markov competition. Instead, the study has a clear hierarchy:

- **Dijkstra** is the main validated framework
- **Markov** is a secondary exploratory extension

The main paper direction is now much sharper than at the start of the discussion.

## Refined scientific framing

The project is now centered on four linked themes:

1. **Square versus hexagonal grids**
   - explicitly compare the previous square-grid framework against a new hex-grid framework
   - aim to improve realism and possibly predictive fit, especially at high latitudes

2. **Decadal mean validation**
   - first benchmark both grid types using decadal mean seasonal fields
   - compare simulations against the decadal mean observed tern flyway from the first paper

3. **Interannual variability and behavioural flexibility**
   - use yearly seasonal mean climate fields
   - quantify annual deviations from the decadal mean flyway
   - test how changing movement weights affects the ability to maintain a similar flyway across years

4. **Markov accessibility extension**
   - start from a Southern Ocean mask
   - no predefined destination
   - use Markov transitions to explore climatically accessible movement space
   - treat this as exploratory and biogeographical, not as the main validation core

## Important conceptual decisions made

- The main biogeographical point is that **climate sets the limits or boundaries within which birds operate**.
- The Markov framework is meant to show **climatically accessible regions** where birds could move, including regions not yet observed in tracking data.
- The first paper’s limitations that this sequel should address are:
  - too path-centric
  - not enough route uncertainty
  - inability to represent corridor width
  - too coarse spatial structure
  - geometric problems of square grids near the poles
- For the Markov model, one step currently means **one movement to a neighboring hexagon**.
- Seasonal-average climate is assumed fixed over the migration period, approximately 90 days.
- For Dijkstra, birds are assumed to have a destination.
- For Markov, birds do not have a predefined destination.
- Markov is not better or worse than Dijkstra, it answers a different question.

## Stronger paper theme identified during discussion

A stronger central paper theme emerged:

**flyway stability under interannual climatic variability and the behavioural flexibility required to maintain similar flyways through time**

This may become the main scientific contribution, with the hex-grid comparison as the methodological improvement and Markov as the exploratory extension.

## Experimental design choices discussed

### Environmental data structure
- use seasonal averages from individual years
- compare annual flyways to the decadal mean flyway
- use the decadal mean benchmark first for the square-versus-hex comparison

### Validation references
Two reference objects should be distinguished:
- the **observed decadal mean flyway** as the biological benchmark
- the **simulated decadal mean flyway** as the climate-model baseline

### Metrics
- RMSE to the decadal mean flyway remains the main candidate metric
- RMSE alone is probably not enough
- a second positional metric should be included, likely something like median longitudinal deviation by latitude band or an equivalent interpretable positional metric

### Weight sets
- the user suggested testing different weight combinations for wind, food, crosswind, and distance
- practical recommendation was to start with a **coarse weight-set table**, not a dense search

### Starting condition for Markov
- initial idea: a Southern Ocean mask for non-breeding arctic terns
- this also allows testing sensitivity to starting location

### Scope control
- begin with **one tern population** first
- do not start with all populations at once

## Open issues raised

- how to make the square-versus-hex comparison fair
- whether crosswind should be included in the first coarse model set or added later
- what the exact secondary metric should be alongside RMSE
- whether grid geometry and polar distortion should be quantified directly, not only predictive fit
- whether the Markov process should allow staying in place
- how broad the Southern Ocean starting mask should be
- whether the project is becoming too broad for one paper
