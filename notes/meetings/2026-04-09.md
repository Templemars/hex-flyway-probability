### 5. Environmental transfer to H3 decided explicitly
A key design question was how to transfer environmental data from the 1° benchmark support to the H3 grid.

Decision:
- do **not** use raw square-point aggregation into H3 as the first method
- instead, use **H3 centroid sampling** from the 1° benchmark environmental field
- for the first prototype, use **nearest-neighbor assignment**
- treat `u10` and `v10` as the primary wind variables
- do not directly average wind direction as an angle

Reasoning:
- avoids empty H3 cells
- keeps the method simple and explicit
- is easier to debug and explain than aggregation plus gap-filling

## rWind lineage clarified

The `rWind` repository was checked explicitly because it is part of the methodological ancestry of the previous project.

Key takeaway:
- the old movement framework is strongly rooted in **anisotropic, directional transition modelling** rather than a simple undirected resistance surface

This matters because it supports the current sequel design choice:
- the H3 version should preserve the directional edge-cost logic
- but replace the old stack with Python + H3 rather than R + raster / gdistance

Preserve from the old lineage:
- direction-sensitive movement costs
- anisotropy
- transition-based path modelling

Replace in the sequel:
- R implementation
- square-grid dependence
- implicit package-default logic that is not written down in our own code and notes

## Standardization and distance-term decision

After checking the exact 2025 paper logic, the component standardization strategy is now clearer:
- the old model used **P99-based standardization to 0-100 SCU** for the major varying components
- distance in the old model was a **constant per-step penalty**, derived from `P50(w_cost)` rather than a spatially varying distance field

Decision for the H3 sequel:
- preserve the **P99-based standardization philosophy**
- adapt the **distance term** to true H3 edge length rather than keeping the old constant-per-step proxy

Interpretation:
- this keeps the published scaling logic where it is scientifically strong
- but treats distance as an intentional methodological refinement made possible by the H3 graph representation
