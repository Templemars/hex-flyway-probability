# Working-text references

This folder stores machine-converted text/Markdown copies of especially important papers.

## Purpose

These files exist for:
- fast searching
- quick quotation and method lookup
- easier internal reference while writing code, notes, and reports

## Important warning

These are **not** the authoritative paper versions.
The authoritative sources remain the original PDFs in `refs/core/`, `refs/methods/`, or `refs/background/`.

## When to create a working-text copy

Only for papers that become heavy repeated references in the project.
Do not convert everything by default.
