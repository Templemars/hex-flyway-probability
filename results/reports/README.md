# Reporting workflow

## Purpose

This folder stores short human-readable milestone reports for the project.

Markdown is the source format.
PDF export is optional and can be added later when useful.

## Recommended structure for a report

- Question
- Input data
- Method
- Key results
- Small summary table
- 1 to 3 figures
- Interpretation
- Next step

## Principle

A good report should be quick to read and sufficient for supervision.
It should summarize the outputs of scripts rather than replace the scripts themselves.
